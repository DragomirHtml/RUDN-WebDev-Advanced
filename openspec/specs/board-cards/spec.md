## Purpose

Позволяет пользователю управлять карточками на Kanban-доске: добавлять, отображать и удалять карточки с подтверждением действия.

## Requirements

### Requirement: Карточка имеет элемент управления удалением

Каждая отображаемая карточка на доске SHALL содержать видимый элемент управления для удаления (например, иконка «удалить» или кнопка «Удалить»).

#### Scenario: Элемент удаления виден на карточке

- **WHEN** пользователь открывает доску с карточками
- **THEN** на каждой карточке отображается кнопка или иконка для удаления

#### Scenario: Элемент удаления виден только на карточках в списке

- **WHEN** пользователь навёл курсор на карточку (или нажал на неё на мобильном устройстве)
- **THEN** элемент управления удалением становится видимым и доступным для нажатия

### Requirement: Удаление карточки требует подтверждения

При попытке удаления карточки система SHALL запросить у пользователя явное подтверждение действия.

#### Scenario: Подтверждение при клике на «Удалить»

- **WHEN** пользователь нажимает на элемент управления удалением на карточке
- **THEN** система показывает диалог подтверждения с текстом «Удалить карточку? Это действие нельзя отменить» и кнопками «Удалить» и «Отмена»

#### Scenario: Подтверждение с названием карточки

- **WHEN** пользователь нажимает на элемент управления удалением на карточке
- **THEN** в диалоге подтверждения отображается название удаляемой карточки

### Requirement: После подтверждения карточка удаляется

При подтверждении удаления карточка SHALL быть удалена с сервера, исчезнуть с доски без перезагрузки страницы и оставаться удалённой после перезагрузки (F5).

#### Scenario: Удаление после подтверждения

- **WHEN** пользователь нажимает «Удалить» в диалоге подтверждения
- **THEN** система отправляет DELETE-запрос на сервер для удаления карточки

#### Scenario: Карточка исчезает с доски сразу после удаления

- **WHEN** сервер подтвердил удаление карточки
- **THEN** карточка немедленно исчезает с доски без перезагрузки страницы

#### Scenario: Карточка остаётся удалённой после перезагрузки

- **WHEN** пользователь нажимает F5 (перезагружает страницу)
- **THEN** удалённая карточка не появляется в списке — она отсутствует на доске

#### Scenario: Ошибка удаления отображается пользователю

- **WHEN** сервер вернул ошибку при удалении карточки
- **THEN** система показывает пользователю сообщение об ошибке и карточка остаётся на доске

### Requirement: При отмене подтверждения удаление не выполняется

При отмене подтверждения карточка SHALL остаться на доске, удаление не выполняется.

#### Scenario: Отмена удаления через кнопку «Отмена»

- **WHEN** пользователь нажимает «Отмена» в диалоге подтверждения
- **THEN** диалог закрывается, карточка остаётся на доске без изменений

#### Scenario: Закрытие диалога по нажатию Escape или клику вне области

- **WHEN** пользователь закрывает диалог подтверждения любым способом кроме кнопки «Удалить»
- **THEN** карточка остаётся на доске, удаление не выполняется
