## Why

У карточки Kanban-доски есть признак «выполнено» (`isDone`), который приходит с сервера и отображается на UI (приглушение, зачёркивание, фильтр). Однако поставить эту отметку невозможно — на доске нет элемента управления для её установки или снятия. Из-за этого фильтр «Скрыть выполненные» бесполезен: скрывать нечего, кроме карточек, которые были отмечены изначально.

## What Changes

- На карточке появляется элемент управления, которым отметка «выполнено» ставится и снимается обратно
- Отметка сохраняется на сервере: после обновления страницы карточка остаётся в том же состоянии
- Сервер принимает изменение отдельным эндпоинтом, адресованным конкретной карточке
- Запрос с негодным значением отметки отклоняется кодом 400 промежуточной функцией (middleware)
- Попытка изменить несуществующую карточку возвращает 404

## Capabilities

### New Capabilities

- `card-status`: Отметка карточки как выполненной/невыполненной. Включает серверный эндпоинт для частичного обновления поля `isDone`, валидацию входных данных в middleware, клиентский элемент управления на карточке.

### Modified Capabilities

- `board-cards`: Добавлена возможность изменения состояния карточки (поле `isDone`) через новый эндпоинт.

## Impact

- **Сервер:** `server/services/cards.service.ts` — добавить функцию `toggleCardDone(id, isDone)`; `server/controllers/cards.controller.ts` — добавить контроллер; `server/routes/cards.router.ts` — добавить маршрут `PATCH /cards/:id`; `server/middlewares/validateDone.ts` — middleware валидации `isDone`; `server/types/card.ts` — не менять (поле уже есть)
- **Клиент:** `client/src/api/cards.ts` — добавить функцию `toggleCardDone(id, isDone)`; `client/src/components/BoardCard/BoardCard.tsx` — добавить кнопку/чекбокс для переключения; `client/src/components/BoardCard/BoardCard.module.css` — стиль для кнопки
- **Зависимости:** новые не требуются, используется уже подключённый Express
