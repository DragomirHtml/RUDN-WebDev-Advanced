## Why

На доске Kanban нет способа удалить карточку — ни ошибочно созданную, ни просто ненужную. Один раз добавленная карточка остаётся навсегда. Пользователь не может управлять списком задач полноценно, что снижает практичность доски как инструмента.

## What Changes

- Пользователь получает возможность удалить карточку с доски
- Удаление требует явного подтверждения (диалог подтверждения)
- После успешного удаления карточка исчезает с доски и не восстанавливается при перезагрузке страницы (удаление сохраняется на сервере / в JSON Server)
- Список карточек на клиенте обновляется через React Query после успешного удаления

## Capabilities

### New Capabilities

- `board-cards`: Управление карточками доски — создание, отображение, удаление карточек. Включает поведение UI (подтверждение удаления, обновление списка) и серверное взаимодействие (DELETE-запрос).

### Modified Capabilities

_Нет — существующих спецификаций в проекте нет._

## Impact

- **Клиент:** `client/src/api/cards.ts` — добавить функцию `deleteCard(id)`, `client/src/components/BoardCard/BoardCard.tsx` — добавить обработчик удаления, `client/src/components/BoardColumn/BoardColumn.tsx` — пробросить колбэк удаления, `client/src/App.tsx` — создать мутацию удаления и передать вниз
- **Зависимости:** новые не требуются, используется уже подключённый `json-server` (встроенный DELETE-эндпоинт)
- **Бэкенд:** изменения не требуются, JSON Server поддерживает `DELETE /cards/:id` из коробки
